## MATLAB 与 Simulink

打开上面的固定版本链接并查看 MathWorks 上游安装说明。以下要求对应盘点记录中的工作流版本。

- `matlab-analyze-spectrum`。MATLAB R2024b 或更新，Signal Processing Toolbox。
- `matlab-identify-linear-system`。MATLAB R2021a 或更新，System Identification Toolbox。
- `building-simulink-models`。MATLAB R2023a 或更新，Simulink；特定模型还需 Stateflow、System Composer 或 Simscape。
- `simulating-simulink-models`。MATLAB R2023a 或更新，Simulink。
