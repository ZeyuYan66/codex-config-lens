# 实验演示剪辑

[English workflow](references/guide.en.md)

先确认目标时长、横竖屏、要留的现场声音和必须可读的仪表或屏幕。对已有素材记录文件名、时长及可用的入点和出点。口播内容以用户给出的台词或实际听到的原声为准。只要镜头表时可用文字素材完成。

1. 把同一次实验的操作、测量条件和结果对应起来。保留足够观察读数的时间。横竖屏裁切前，逐镜标出不能裁掉的标尺、曲线图例或指示灯。
2. 按实际播放顺序制作 UTF-8 CSV 镜头表，列名和填写示例见 [shots.csv](assets/shots.csv)。`in`、`out` 是**源文件秒数**，最多三位小数，每行代表一个正常速度、硬切的镜头。`caption` 可留空，空行字幕对应的镜头仍占时间。字幕属于整个镜头，需要逐句对齐时拆成多行。
3. 在此技能目录运行 `python scripts/timeline.py shots.csv --srt demo.srt`。命令输出剪后入点和出点，并写出 UTF-8 字幕。在剪映或其他编辑器中按表剪切，再在时间线零点导入字幕。变速、交叠转场和分离音轨的项目应按编辑器的最终时间线重新对齐。
4. 若用户要成片，使用实际可用的编辑器或 FFmpeg 导出到新文件。逐段检查读数、同期声和字幕。在有 FFprobe 的环境中可用以下命令读回时长、画面尺寸和音视频流，然后抽看第一帧、关键读数和最后一个镜头。

```sh
ffprobe -v error -show_entries format=duration:stream=codec_name,codec_type,width,height -of json demo.mp4
```

示例镜头表使用虚构文件名和文案，可以直接试算字幕。剪成实际视频时替换为真实素材，核对每段出点在相应文件长度内。
