# 工程课程设计与演示

[English workflow](references/guide.en.md)

先从用户要交的东西确定工作范围。交付物可能是一张有尺寸的图、一份有数据支撑的结论，或一段能看清实验现象的演示。一个文件能回答的问题，就直接完成那个文件。

| 要交什么 | 从哪里开始 | 交付前怎样复核 |
| --- | --- | --- |
| 支架、外壳、装配作业 | 用已安装的 `cadquery-llm` 做参数化几何。将螺孔中心距、板厚、插头活动区分别记录，标明实测还是按图估计。 | 回读导出的 STEP 或 STL，核对单位、包围盒及孔位。打印可行性另看具体材料、喷嘴和切片预览。 |
| 实验数据和课程报告 | 保留原始表。从列名确认采样量、单位和时间基准；缺失值、量程截断和重复样本单独统计。选择能检验问题的图。 | 图表注明单位、样本数和处理方法。用一行实际数据演算一次，保留能复现图表的脚本或公式。 |
| 嵌入式演示 | 区分固件预期行为、串口日志和镜头里可见的现象。在报告里把每个性能数字指回一次测量。 | 没有板卡时交付可运行的主机侧检查，并在结果旁说明还有哪项需在实板上验证。 |
| 实验演示短片 | 用 `lab-demo-edit` 整理镜头，按“要证明什么 → 怎么测 → 看到了什么”选素材。让画面和字幕使用同一测量结果。 | 检查首尾、切点、读数可辨性、音轨和片长；向用户交付剪辑清单与字幕，按要求另交成片。 |

按需交给相应的已安装技能。缺少专用程序时，仍可完成尺寸表、数据检查、镜头表等可验证部分。引用数据、照片与视频时保留原文件名和时间位置，方便队友追溯。
