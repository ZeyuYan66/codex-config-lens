# v0.1.0 — Local configuration sources, in two languages

Codex Config Lens compares user and project configuration files and explains confirmed errors without claiming to resolve the active settings of a session.

- English and Simplified Chinese UI, CLI exports, and companion Codex skill.
- TOML syntax, explicit project trust, and absolute local MCP script checks.
- Optional Codex doctor with bounded execution and schema fallback.
- Previewable sanitized Markdown reports and six-setting TOML templates.
- Three offline before/after demos, Windows CI, and MIT license.

Requires Windows and Node.js 24+. Demo/static modes need no account, API key, or installed Codex. Run `npm ci` then `npm start`. See the README for privacy boundaries and supported doctor structure. This is a third-party utility, unaffiliated with OpenAI.
