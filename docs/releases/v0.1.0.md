# v0.1.0

First release of Codex Config Lens, a local tool for comparing user and project Codex configuration files on Windows.

The interface and CLI exports support English and Simplified Chinese. A companion Codex skill uses the CLI to explain scan results.

Checks cover TOML syntax, explicit project trust records, and absolute local MCP script references. Codex doctor is optional, with execution limits and a fallback for unsupported report structures. The comparison cannot determine the active settings of a session.

You can preview a sanitized Markdown report or a TOML template containing six supported settings before downloading it. Three offline demos show results before and after a sample fix. The source includes Windows CI and uses the MIT license.

Requires Windows and Node.js 24+. Demo/static modes need no account, API key, or installed Codex. Run `npm ci` then `npm start`. The README explains the privacy limits and supported doctor structure. This is a third-party utility, unaffiliated with OpenAI.
